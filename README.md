# o'NeuroNet: алгоритмы анализа сновидений (методическое руководство)

## Преамбула

Методические материалы по алгоритмическому анализу сновидений. Это практическое руководство по работе с личными дневниками сновидений методами выборки, классификации и статистического сопоставления. Цель — превратить разрозненные записи в проверяемые данные: выделить повторяющиеся мотивы, привязать их к событиям накануне, оценить частоту и контекст появления образов.

## Будущие структура и содержание

- принципы формирования выборок из записей (критерии включения, временные окна, фильтрация шума);
- алгоритмы разметки символов и сюжетов, словарь типовых образов и их рабочих значений;
- методы сопоставления сновидений с событиями дня, поиск корреляций без ложных выводов о причинности;
- инструменты реализации: DataView в Obsidian, скрипты для обработки файлов, использование нейросетей для рутинной разметки и анализа больших объёмов текстов;
- этика и ограничения: работа ведётся только с собственными записями, результаты носят исследовательский характер и не являются диагнозами или предсказаниями.
